Convert a Date to Unix Timestamp

Create a Unix timestamp from a recognizable date and time.

Short answer

To create a Unix timestamp from a date, specify the full date, clock time, and timezone before converting. Leaving out the timezone can shift the resulting instant.

When this applies

Use this for API requests, scheduled jobs, test fixtures, database fields, and time-based filters that require a numeric Unix value.

Practical review steps

  1. Use an unambiguous date format and include the timezone.
  2. Confirm whether the receiving system expects seconds or milliseconds.
  3. Round-trip the output back to a date before submitting a critical value.
